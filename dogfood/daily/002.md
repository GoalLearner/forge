**A finding worth recording.** `MAX_STAT_XP` is *derived* in source
(`var MAX_STAT_XP = xpForLevel(MAX_STAT_LEVEL);`), so the identity assertion
`xpForLevel(MAX_STAT_LEVEL) === MAX_STAT_XP` is tautological by construction —
both sides drift together and it can never fail. Mutation 3 demonstrates this:
the XP table changed, the identity test still passed, and it was the **literal
pin** `MAX_STAT_XP === 6650` that caught the drift.

The task asked for both, and Forge wrote both, so coverage is correct. But the
identity test contributes nothing on its own; the literal pin is doing the work.
